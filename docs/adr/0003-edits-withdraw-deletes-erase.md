# Source edits withdraw Memories; Source deletions erase them

Muninn normally never overwrites history, but source changes are treated differently depending on what the author did. When a Source is edited, Memories citing the old Source Revision lose that Evidence. If they have nothing left, they become `withdrawn` and stay visible in history, because the conversation really did say that at the time. When a Source is deleted, Muninn erases everything derived from it (Evidence, embeddings, and any Memory left without support) and keeps no history, because deletion means the author or an admin chose to remove it, and privacy wins over completeness. Without this record, a future reader could reasonably "fix" deletes so they withdraw like edits, or edits so they erase like deletes.
