# Bruh is licensed under Apache-2.0

Bruh is open source first, and a commercial hosted service is only a possibility for later. Apache-2.0 is permissive, includes a patent grant, and is widely approved inside companies, all of which help community adoption. AGPL-3.0 was rejected because many companies block AGPL software internally. FSL and BSL were rejected because they aren't OSI-approved open source. Any later commercial offering would compete on hosting, setup, scale and managed integrations, not on keeping code closed. Changing the license after outside contributions arrive is hard, which is why the license is in place from the first commit.
